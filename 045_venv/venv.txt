Virtual environment
An isolated Python environment for a project.
Reason 1 — Avoid dependency conflicts
Reason 2 — Keep projects isolated
Reason 3 — Easier project sharing >>> requirements.txt
Reason 4 — Avoid modifying your system Python

Global packages
Global packages are installed into a Python environment that is available outside a specific project.

Project packages
Project packages are installed inside the virtual environment belonging to a particular project.

venv is Python’s built-in module for creating virtual environments.
create a venv >>> python3 -m venv venv
python3 means run python, -m means run module as a command, venv means Use Python’s built-in virtual-environment module, venv is the name of the virtual environment directory.

Creating an environment isn’t enough.
You need to activate it.
Since you’re using macOS, the command you’ll commonly use is: source my_venv/bin/activate
(venv) >>> indicates that virtual env is active now


When you’re finished working with the environment: deactivate

Usually, you do not upload the venv folder to GitHub. >>> so we a make a folder called as requirements.txt


pip is Python’s package installer and package manager.
It allows you to:
* install packages
* uninstall packages
* upgrade packages
* check installed packages
* see package information
* install packages from a requirements.txt file

e.g >>> pip install pandas

Python comes with a large standard library (os, json, re etc), but it doesn’t contain every tool you’ll ever need (pandas numpy matplotlib etc). These packages can be installed using pip.

You can install multiple packages in one command: pip install pandas numpy seaborn

You can specify a package version. >>> pip install pandas==2.2.3
==     exactly this version
>=     this version or newer
<=     this version or older
>      newer than
<      older than


checking installed packages >>> pip list
if (venv) is active "pip list" will show us packages belonging to this v_env
if (venv) is no active "pip list" will show us global packages

checking a particulat package >>> pip show pandas

pip freeze >>> It displays installed packages in a format such as: 
pandas==2.3.3
python-dateutil==2.9.0.post0
pytz==2026.4
this format is commonly used to create requirments.txt

uninstalling a package >>> pip uninstall pandas >>>this will ask for a confirmation
uninstalling a package without confirmation >>> pip uninstall -y pandas


upgrading a package >>> pip install --upgrage pandas or pip install -U pandas


requirements.txt >>>  is a text file that contains the Python packages required by a project, usually along with their versions.
pandas==2.2.3
numpy==2.1.3
matplotlib==3.9.2
openpyxl==3.1.5
this is the projects dependency list

creating a requirements.txt >>>
1. manually >>> we will create a requirements.txt and then write

but this can become hectic at times so we do this
